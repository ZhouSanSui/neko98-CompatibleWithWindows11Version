------------------------------------------------------------------------
  二、这一版修好了什么
------------------------------------------------------------------------

1. 双屏显示
   原来小猫和脚印会跑到两块不同的屏幕上。现在渲染方式整个重写过，
   小猫和脚印画在同一张位图上、一次提交，必定在同一个屏幕。

2. 脚印的白底色块
   原来是图标自带的透明信息不可靠。现在程序自己从图标的 AND 掩码
   推导出透明度，背景完全透明、不留色块。

3. 中文化
   设置程序的全部对话框、按钮、提示，以及托盘菜单，都改成了中文。

4. 小猫时不时跳动
   原来移动窗口和更新画面分两步，中间会出现"新位置配旧画面"的瞬间。
   现在合并成一次原子操作，实测连续 140 步偏移为 0 像素。

5. 开机自动启动（新增）
   设置里勾选即可，写的是当前用户的启动项，不需要管理员权限。
   ⚠ 顺带修掉一个真问题：旧版本勾选后记下的是设置程序 NekoCFG.exe，
     所以开机只会弹出设置窗口、看不到小猫。现在固定记 Neko98.exe，
     并且启动时会自动把旧的错误记录改回来。

6. 两个可自定义的全局快捷键
   默认 Ctrl+Alt+N 开关系统代理，Ctrl+Alt+H 循环「放大 / 隐藏 / 唤回」。
   都可以改，也可以留空关闭。
   两个键不允许设成同一个组合（否则其中一个会失效），设置时会提示。
   暂停功能仍在托盘右键菜单里。

7. 跨屏时“卡在屏幕边上、来回跑”（第 2 版重点修复）
   这个 bug 只在“两块屏幕缩放比例不同”时出现（例如 100% + 150%）。
   原因是小猫判断“到了没有”用的尺寸，会随所在屏幕的缩放比例变化：
   100% 的屏幕上是 32 像素，150% 的屏幕上是 48 像素。于是“停靠线”
   会在跨越接缝的一瞬间移动 16 像素——恰好落在这条缝附近的十几个
   目标点，小猫会永远在两边来回跑，而且因为一直处于“移动”状态，
   也不会触发重新选目标。现在判断到达改用“与缩放无关的基础尺寸”，
   实测：修复前有 16 个目标点永远停不下来（6000 帧里反复穿越接缝
   5799 次），修复后 121 个目标点全部在 12~14 帧内停稳；另外还加了
   一道反转看门狗作为兜底。横向排列的双屏同样有效。

8. 开机启动项被“临时目录里的副本”劫持（第 2 版修复）
   旧版本的自动启动修正逻辑只要发现启动项路径和当前运行的程序不一致，
   就直接改成当前路径。而本安装包是自解压的，7-Zip 会先解压到
   %TEMP%\7zXXXX.tmp、程序退出后再把这个目录删掉——一旦从临时目录
   运行过，启动项就会被指向一个已经不存在的文件夹，下次开机自然失败；
   手动从别处的副本运行，也会悄悄“抢走”您已经设好的启动项。
   现在改成三条规则：只要启动项指向的文件真实存在（并且不是设置程序
   NekoCFG.exe）就一律不动；只有指向的文件确实已经不在了才修正；
   从 7z*.tmp 这样的临时目录运行时根本不写启动项。

9. 另外还有 19 项优化
   包括托盘图标在资源管理器重启后自动恢复、小猫可以直接拖动、
   会话/电源恢复后界面自动刷新、渲染性能提升（一个动作周期只合成 1 次
   而不是 2 次）、设置值的合法性校验、内置中文帮助（原来的帮助按钮是
   坏的）、以及 DPI 感知修复（原来小猫在 150% 缩放的屏幕上会被拉伸模糊）。

### 12. 程序在跑、小猫却不在桌面上（v4.1 重点修复）

“窗口可见”和“你能看见”是两件事。实测三条失效路径都不会让 `IsWindowVisible()` 变成假：

1. 坐标停在所有显示器之外（改过分辨率、拔过外接屏之后）；
2. 被别的置顶窗口压住（本机实测抓到全屏置顶的 `ShellHandwritingCanvas` 就盖在小猫上面）；
3. 隐藏期间分层表面被合成器丢弃，重新显示出来是一块空白。

修法：新增 `ForceShow()`，六步强制唤回——重读虚拟桌面尺寸 → 把坐标夹回可见区 → 重新抢回置顶层级 → 丢弃并按当前缩放重建贴图 → 重新合成 → 最后核对是否真可见。
“隐藏 → 显示”走的就是这条路。

### 13. 隐藏快捷键改成三态循环（v4.1 新增）

`Ctrl+Alt+H` 按下后依次是：正常大小 → **放大到 300%** → **隐藏** → **强制唤回并恢复正常大小**。

- 放大的只是小猫本身（32 → 96 像素，在 150% 屏幕上再乘屏幕缩放），**不是把窗口拉大**，所以拖动、脚印、点击判定都会自动跟着变。
- 倍数不会复利叠加：实测 32x32 → 96x96 → 精确回到 32x32 → 第二轮仍然 96x96。
- 放大状态**不写注册表**，避免下次开机就是三倍大。
- 托盘菜单里也有对应的「放大小猫 300% / 恢复正常大小」。

### 14. 原「暂停」快捷键改成系统代理开关（v4.1 新增）

按 `Ctrl+Alt+N` 打开系统手动代理：地址 `192.168.10.210`、端口 `7890`，同时勾选「请勿将代理服务器用于本地地址」，并预填好不走代理的地址列表。再按一下关闭。

- 只改当前用户的设置，**不需要管理员权限、不弹 UAC**。
- 写完会主动通知系统“Internet 设置已变化”，**浏览器不用重启就生效**。
- **已经手工填过的绕过列表不会被覆盖**。
- 写入失败会明确提示，不会静默失败。
- 暂停功能仍保留在托盘右键菜单里。

### 15. 代理开启时一侧脚印变白（v4.2 新增）

代理开着的时候，小猫走过留下的脚印里会有一半是白色的——它是左右脚交替踩出来的，所以看起来就是“一侧白、一侧深”。不打开任何窗口，低头看一眼脚印就知道代理到底开没开。

- 颜色在脚印落下的那一刻就定死，所以关掉代理时已经在淡出的旧脚印不会被倒回去改色。
- 白色是重新描出来的同一只爪子（保留原来的轮廓和透明度），不是盖一个白方块。
- 放大小猫（三态循环的第二个状态）时，白色脚印会同步放大。
- 不需要任何设置，完全跟着系统代理状态走。

### 16. 快捷键系统重构（v4.3 新增）

声音功能整个移除，原来的「声音」页改成「快捷键」页，把之前写在「常规」里的两个固定快捷键也搬了进去。

**五种功能类型**（顶部下拉框选中后点「+」添加）：

| 类型 | 说明 | 专属设置 |
| --- | --- | --- |
| 隐藏/缩放 | 三态循环：正常 → 放大 300% → 隐藏 → 强制唤回 | 无 |
| 代理 | 开关系统手动代理 | 服务器地址 + 端口（新建默认 `192.168.1.1:7890`） |
| 禁止自动休眠 | 阻止自动睡眠与熄屏，再按释放 | 无 |
| 打开网站 | 用指定浏览器打开网址 | 浏览器（Edge / Chrome / 自定义）+ 网址 |
| 投影方式 | 在两套投影状态间切换 | 两个下拉框：屏幕1 / 屏幕2 / 扩展 / 辅助（不可相同） |

**列表交互**：下方两列「快捷方式功能 / 快捷键」；点某一行的功能名展开该条的专属设置，再点一下收起。同一功能可以添加多条——两个不同网址、两个不同代理各占一行、各用自己的快捷键。每条都能单独删除。

**几个实现要点**：

- 数据模型 `NEKOHOTKEY { DWORD dwType; DWORD dwHotkey; char szP1[512]; char szP2[512]; }`，整张表存在一个 `REG_SZ` 值 `HotkeyList` 里，一行一条、TAB 分隔。空表也写回空串，以便区分“用户删光了”和“从没跑过”。
- 类型值是**持久化**的，只能追加不能重排。
- 注册从“两个固定槽位”改成遍历列表：`RegisterHotKey` 的 id 从 `NEKO_HOTKEY_ID_BASE = 100` 起按列表下标递增。
- 投影切换调 `DisplaySwitch.exe`：屏幕1 → `/internal`、屏幕2 → `/external`、扩展 → `/extend`、辅助 → `/clone`。交替状态记在内存里，第一次按一定应用左边那个。
- 禁止自动休眠用 `SetThreadExecutionState(ES_CONTINUOUS|ES_SYSTEM_REQUIRED|ES_DISPLAY_REQUIRED)`，按线程生效，所以从活到进程结束的 GUI 线程调用；进程退出自动释放。
- 打开网站时 URL 作为**独立参数**传给 `ShellExecuteA`，不拼进命令串——含 `&` 的网址否则会被当成命令分隔符。

**升级迁移**：只在 `HotkeyList` 键完全不存在时，才把旧版的两个 `Hotkey` / `HideHotkey` 迁移成两条记录（代理那条用旧的 `192.168.10.210:7890`）。列表存在但为空就尊重用户的选择，不会把默认值填回去。

**修掉的两个 bug**：
1. 设置程序打开约 5 秒后自己消失（`0xC00000FD` 栈溢出）——新页在 `LVN_ITEMCHANGED` 里调用的函数内部又 `ListView_SetItemState()`，无限递归。加了 `s_bInNotify` 守卫，并把展开/收起改到 `NM_CLICK` 只对“当前已选中行”生效。
2. `SleepGuardToggle()` 返回的是“操作是否成功”而不是“切换后的状态”，关闭时也返回 TRUE，导致托盘提示显示反的。改成返回真实状态。这个是新写的单测抓出来的。

### 17. 设置界面的标签页与内容对不上（v4.3.1 修复）

现象：点「快捷键」标签，标签高亮了，下面显示的却还是「显示」页的内容；
有时点一个标签却跳到另一个，像是鼠标点歪了。

**两个原因叠在一起：**

1. **多行标签会把选中行搬到最下面。**
   `IDC_TABS` 用了 `TCS_MULTILINE`，而 5 个「文字 + 16px 图标」的
   标签在 159 对话框单位里排不下，折成两行。comctl32 在当前选中项
   变化时会把选中项所在那一行**整体挪到最下面一行**——
   每点一次，所有标签文字都换行重排，同一个像素位置连点两下
   会落到不同标签上。实测（在目标进程内分配 `RECT` 读
   `TCM_GETITEMRECT`，因为跨进程 `SendMessage` 不封送指针）：

   ```
   选择项 = 0          点击第 3 个标签后
   [0] 2,23-139,44     [0] 2,2-139,23      <- 两行整体交换
   [2] 2,2-94,23       [2] 2,23-94,44
   ```

2. **页面从未被移动。** 5 个页面是 `CreateDialog()` 创建的，保留模板坐标
   （父窗口左上角）。旧代码只在 `OnSelChanged()` 里移动当前要显示的那一页，
   所以从未显示过的页面第一次出现时仍画在左上角，标签区里留的还是上一页的
   像素。探针实测修复前 `inside the tab body: 1 of 5`（只有第 0 页在
   `1266,577`，其余 4 页全在 `1007,521`）。

**修复：**

- 标签控件去掉 `TCS_MULTILINE`，并去掉每个标签左侧的图标（`TabCtrl_SetImageList`
  整个删除，`TCITEM.mask` 去掉 `TCIF_IMAGE`）。每个图标约占 22px 标题宽度，
  去掉后 5 个标题总宽 229px 正好排进一行，**点击前后几何完全不变**。
- 启动时把 5 个页面**全部**在隐藏状态 `SetWindowPos` 摆进标签区；页面顶端改成
  从 `TabCtrl_GetItemRect` 的最大 `bottom` 推导，不再写死 `+42`。
- 切换时隐藏所有非当前页，再 `ShowWindow` + `SetWindowPos(HWND_TOP, ...)`。
- 保留 `if( iSel < 0 || iSel >= NUM_PAGES ) return;` 守卫——`TabCtrl_GetCurSel()`
  在按下到抬起之间会瞬时返回 -1，旧代码用它索引 `tibTabs[]` 拿到野指针交给
  `ShowWindow()`，进程直接以 `0xC000041D` 死亡（修前实测能崩出来）。

**验证：** 新增 `probe_tabs5.exe`（9 项断言）——不只问“逻辑上哪页可见”，
而是用 9 个采样点 `WindowFromPoint` + `GetParent` 上溯判定“屏幕最上层实际
渲染的是哪一页”，且采样矩形**从标签控件推导**（若按各页自身矩形采样，页面
错位时会“自证所见即所选”，缺陷正好隐身）。修复后 `inside the tab body: 5 of 5`，
5 个标签逐个点击全部 `selected=N seen=N`。旧版同款探针是 `8 passed, 1 failed`。

**这次最值得记的一条方法论：** 三种注入方式（键盘、`PostMessage` 点击、
真实鼠标）都复现不出来时，**“测不出来”不等于“没有问题”**——真正推动进展的是
换度量（从“逻辑可见”换成“实际渲染在最上层”）和加断言（每页是否落在标签区内）。
另外做观测工具时要先问一句：“我的观测方式会不会恰好让这个 bug 隐身？”
