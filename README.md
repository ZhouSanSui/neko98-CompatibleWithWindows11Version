# neko98--win11-
功能是在屏幕上显示一只奔跑的小猫。工程是基于neko98不知道那一版的也不记得是哪儿下的源码重新适配了一下win11。

========================================================================
  Neko98 桌面小猫 — Windows 11 修复与优化版
  源码 + 成品 完整交付包
========================================================================

打包日期：2026-10-11
适用系统：Windows 11 / Windows 10 (64 位)

------------------------------------------------------------------------
  一、怎么用
------------------------------------------------------------------------

最简单：双击  成品\neko98-win11.exe  ，它会解压好并自动启动小猫。

也可以：把  成品\neko98-win11.zip  解压到一个固定文件夹
        （例如 D:\Neko98），再双击里面的 Neko98.exe。

        注意：别只解压到临时目录。那样在设置里勾选「开机自动启动」时，
        记下的会是临时路径，重启后就失效了。

小猫出现后：
  - 直接用鼠标拖动它即可搬位置。点在它周围的透明区域会穿透过去，
    不会挡住下面窗口的点击。
  - 右键托盘的猫头图标 → 设置，可以改：
      速度快慢 / 大小 / 动作方式 / 脚印 / 是否置顶
      开机自动启动
      两个全局快捷键
      图像库、声音等各标签页的详细选项
  - 托盘的右键菜单里还有「暂停」「隐藏小猫」「退出」。
  - 两个默认快捷键：
      Ctrl+Alt+N   暂停 / 继续（小猫停在原地）
      Ctrl+Alt+H   隐藏 / 显示（连同脚印一起消失）
    两个都可以在设置里改成您喜欢的组合。


------------------------------------------------------------------------
  二、这一版修好了什么
------------------------------------------------------------------------

1. 双屏显示
   原来小猫和脚印会跑到两块不同的屏幕上。现在渲染方式整个重写过，
   小猫和脚印画在同一张位图上、一次提交，必定在同一个屏幕。

2. 脚印的白底色块
   原来是图标自带的透明信息不可靠。现在程序自己从图标的 AND 掩码
   推导出透明度，背景完全透明、不留色块。

3. 中文化
   设置程序的全部对话框、按钮、提示，以及托盘菜单，都改成了中文。

4. 小猫时不时跳动
   原来移动窗口和更新画面分两步，中间会出现"新位置配旧画面"的瞬间。
   现在合并成一次原子操作，实测连续 140 步偏移为 0 像素。

5. 开机自动启动（新增）
   设置里勾选即可，写的是当前用户的启动项，不需要管理员权限。
   ⚠ 顺带修掉一个真问题：旧版本勾选后记下的是设置程序 NekoCFG.exe，
     所以开机只会弹出设置窗口、看不到小猫。现在固定记 Neko98.exe，
     并且启动时会自动把旧的错误记录改回来。

6. 两个可自定义的全局快捷键（新增）
   Ctrl+Alt+N 暂停/继续，Ctrl+Alt+H 隐藏/显示。都可以改，也可以留空关闭。
   两个键不允许设成同一个组合（否则其中一个会失效），设置时会提示。

7. 另外还有 19 项优化
   包括托盘图标在资源管理器重启后自动恢复、小猫可以直接拖动、
   会话/电源恢复后界面自动刷新、渲染性能提升（一个动作周期只合成 1 次
   而不是 2 次）、设置值的合法性校验、内置中文帮助（原来的帮助按钮是
   坏的）、以及 DPI 感知修复（原来小猫在 150% 缩放的屏幕上会被拉伸模糊）。


------------------------------------------------------------------------
  三、如果有问题
------------------------------------------------------------------------

- 托盘菜单和设置界面的中文显示成方块？
  → 控制面板 → 区域 → 管理 → 更改系统区域设置，
    把「非 Unicode 程序的语言」设为「中文(简体，中国)」。
    或者勾选「Beta: 使用 Unicode UTF-8 提供全球语言支持」。

- 快捷键没反应？
  → 可能被别的程序占用了，在设置里换一个组合。
    另外被管理员权限打开的窗口获得焦点时，Windows 不会转发全局快捷键，
    这是系统本身的行为。
